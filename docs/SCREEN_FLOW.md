# 画面フロー設計

このドキュメントでは、ユーザーの操作フローと画面遷移を記載します。

---

## 1. 全体フロー図

```mermaid
graph TD
    A[ユーザーがWebページを開く] --> B[拡張機能アイコンをクリック]
    B --> C[ポップアップ起動]
    C --> D[ページをスキャン]
    D --> E{メディアファイルを検出?}
    E -->|検出あり| F[メディアリスト表示]
    E -->|検出なし| G[空の状態表示]

    F --> H{ユーザーの操作}
    H -->|動画ダウンロード| I[chrome.downloads.download実行]
    H -->|音声抽出| J[メタデータ編集モーダル表示]
    H -->|編集ボタン| J
    H -->|複数選択| K[チェックボックスで選択]

    J --> L{編集するか?}
    L -->|編集する| M[メタデータ入力]
    L -->|スキップ| N[デフォルトのメタデータ使用]
    M --> O[保存してモーダル閉じる]
    N --> O

    O --> P[Service Workerにジョブ送信]
    P --> Q[プログレスバー表示開始]
    Q --> R{ポップアップを閉じる?}
    R -->|閉じる| S[バックグラウンドで処理継続]
    R -->|開いたまま| T[リアルタイム進捗表示]

    S --> U[変換完了]
    T --> U
    U --> V[Chrome通知表示]
    V --> W[アイコンバッジ更新]
    W --> X{通知をクリック?}
    X -->|クリック| Y[ポップアップ再度開く]
    X -->|無視| Z[バッジ表示のまま]

    Y --> AA[完了ジョブリストに表示]
    AA --> AB[ダウンロードボタンクリック]
    AB --> AC[ファイルダウンロード開始]
```

---

## 2. ユーザーフロー詳細

### 2.1 初回起動フロー

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Icon as 拡張機能アイコン
    participant Popup as ポップアップ
    participant Page as Webページ
    participant Storage as Chrome Storage

    User->>Icon: クリック
    Icon->>Popup: ポップアップ起動
    Popup->>Storage: 設定読み込み
    Storage-->>Popup: デフォルト設定返却
    Popup->>Page: スクリプト実行（メディア検出）
    Page-->>Popup: 検出結果返却
    Popup->>Popup: リスト描画
    Popup->>User: メディアリスト表示
```

**画面表示内容**:
- ヘッダー: 「Media Extractor」
- ステータス: 「3件の動画・音声を検出しました」
- リスト: 検出したメディアファイル
- 注意事項: 常時表示

---

### 2.2 動画ダウンロードフロー

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Popup as ポップアップ
    participant Chrome as Chrome Downloads API

    User->>Popup: 「動画ダウンロード」クリック
    Popup->>Chrome: chrome.downloads.download(url)
    Chrome-->>Popup: ダウンロードID返却
    Popup->>User: ステータス更新「ダウンロード中...」
    Chrome->>User: ダウンロード開始（ブラウザのUIで表示）
```

**画面変更**:
- ボタン: 「動画ダウンロード」→ 「ダウンロード中...」（無効化）
- ステータステキスト: 「ダウンロード中: sample_video.mp4」

---

### 2.3 音声抽出フロー（編集あり）

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Popup as ポップアップ
    participant Modal as メタデータ編集モーダル
    participant SW as Service Worker
    participant Storage as Chrome Storage

    User->>Popup: 「編集」クリック
    Popup->>Storage: 現在のメタデータ取得
    Storage-->>Popup: メタデータ返却
    Popup->>Modal: モーダル表示（初期値セット）
    Modal->>User: 編集フォーム表示

    User->>Modal: メタデータ入力
    User->>Modal: 「保存」クリック
    Modal->>Storage: メタデータ更新
    Modal->>Popup: モーダル閉じる
    Popup->>User: UI更新（新しいメタデータ表示）

    User->>Popup: 「音声抽出」クリック
    Popup->>SW: ジョブ送信（URL、メタデータ）
    SW->>Storage: conversionJobs に追加
    SW-->>Popup: ジョブID返却
    Popup->>User: プログレスバー表示開始
```

**画面変更**:
- モーダル表示 → ユーザー入力 → モーダル閉じる
- プログレスバー表示: 0% → 変換中 → 100%

---

### 2.4 音声抽出フロー（編集なし）

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Popup as ポップアップ
    participant SW as Service Worker
    participant Storage as Chrome Storage

    User->>Popup: 「音声抽出」クリック
    Popup->>Popup: デフォルトのメタデータ取得
    Popup->>SW: ジョブ送信（URL、デフォルトメタデータ）
    SW->>Storage: conversionJobs に追加
    SW-->>Popup: ジョブID返却
    Popup->>User: プログレスバー表示開始
```

**画面変更**:
- ボタン: 「音声抽出」→ プログレスバー表示
- ステータステキスト: 「変換中...」

---

### 2.5 バックグラウンド処理フロー

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Popup as ポップアップ
    participant SW as Service Worker
    participant FFmpeg as ffmpeg.wasm
    participant Notification as Chrome通知
    participant Badge as アイコンバッジ

    User->>Popup: ポップアップを閉じる
    Popup->>Popup: ポップアップ終了
    Note over SW: Service Workerは継続

    SW->>FFmpeg: 変換処理継続
    loop 変換中
        FFmpeg->>SW: 進捗通知
    end

    FFmpeg->>SW: 変換完了
    SW->>Notification: 通知表示
    SW->>Badge: バッジ更新「1」
    Notification->>User: 通知表示

    User->>Notification: 通知クリック
    Notification->>Popup: ポップアップ再度起動
    Popup->>User: 完了ジョブリスト表示
```

**画面変更**:
- ポップアップを閉じても処理継続
- 完了時に通知 + バッジ表示

---

### 2.6 複数選択・一括操作フロー

```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Popup as ポップアップ
    participant SW as Service Worker

    User->>Popup: チェックボックスを複数選択
    Popup->>Popup: UIの選択状態を更新

    User->>Popup: 「選択した項目を音声抽出」クリック
    loop 選択した各アイテム
        Popup->>SW: ジョブ送信
        SW-->>Popup: ジョブID返却
    end
    Popup->>User: 各アイテムにプログレスバー表示
```

**画面変更**:
- チェックボックス: ☐ → ☑
- 一括ボタン: 有効化（選択数が1以上の場合）
- 各アイテムにプログレスバー表示

## 4. 状態遷移図

### 4.1 アイテムの状態遷移

```mermaid
stateDiagram-v2
    [*] --> 検出済み: ページスキャン
    検出済み --> 変換中: 音声抽出クリック
    検出済み --> ダウンロード中: 動画DLクリック

    変換中 --> 変換完了: 変換成功
    変換中 --> エラー: 変換失敗
    変換中 --> キャンセル済み: キャンセルクリック

    変換完了 --> ダウンロード中: ダウンロードクリック
    ダウンロード中 --> ダウンロード完了: 成功
    ダウンロード中 --> エラー: 失敗

    エラー --> 検出済み: 再試行クリック
    キャンセル済み --> 検出済み: 再試行クリック

    ダウンロード完了 --> [*]: 削除クリック
```

---

### 4.2 ポップアップの状態遷移

```mermaid
stateDiagram-v2
    [*] --> ロード中: ポップアップ起動
    ロード中 --> スキャン中: Storage読み込み完了
    スキャン中 --> 検出あり: メディア検出
    スキャン中 --> 検出なし: メディア未検出

    検出あり --> モーダル表示中: 編集クリック
    モーダル表示中 --> 検出あり: 保存/キャンセル

    検出あり --> 処理中: 音声抽出/動画DL
    処理中 --> 検出あり: 処理完了

    検出なし --> スキャン中: 再スキャンクリック
    検出あり --> スキャン中: 再スキャンクリック
```

## 7. レスポンシブデザイン

### ポップアップサイズ
- **幅**: 360px（固定）
- **高さ**: 最小400px、最大600px
- **スクロール**: リストが多い場合は縦スクロール

---

## 8. アニメーション

### 8.1 プログレスバーのアニメーション
- スムーズな進捗変化（transition: 0.3s）

### 8.2 モーダルの表示/非表示
- フェードイン/フェードアウト（0.2s）

### 8.3 完了時のアニメーション
- チェックマーク（✅）のフェードイン

---

## 9. アクセシビリティ

### 9.1 キーボード操作
- **Tab**: フォーカス移動
- **Enter**: ボタンクリック
- **Esc**: モーダルを閉じる

### 9.2 スクリーンリーダー対応
- すべてのボタンに `aria-label` を設定
- プログレスバーに `aria-valuenow` を設定
- エラーメッセージに `role="alert"` を設定

---

## 10. 画面要素の優先度

| 優先度 | 要素 | 説明 |
|--------|------|------|
| 高 | メディアリスト | ユーザーが最も頻繁に操作 |
| 高 | 操作ボタン | 主要なアクション |
| 中 | プログレスバー | 処理状況の可視化 |
| 中 | メタデータ編集 | 任意の操作 |
| 低 | 注意事項 | 常時表示だが目立たせない |
