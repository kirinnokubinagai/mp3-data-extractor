# 要件定義書

## 1. 概要

### プロジェクト名

**Media Extractor - 動画・音声抽出Chrome拡張機能**

### 目的

Webページから動画・音声ファイルを検出し、以下の操作を可能にする：

- 動画ファイルをそのままダウンロード
- 動画から音声のみをMP3形式で抽出・ダウンロード
- メタデータ（タイトル、アーティスト等）の編集

### 解決する課題

- Webページ上の動画・音声ファイルを簡単に保存したい
- 動画から音声だけを取り出したい（音楽MVから音源を抽出等）
- ファイルのメタデータを整理したい
- 複数のファイルを効率的に一括処理したい

---

## 2. ユーザー

### 対象ユーザー

- Web上の動画・音声コンテンツを保存したい一般ユーザー
- 個人利用を想定

### 想定規模

- 1ユーザーあたり: 同時に数個〜数十個のファイルを処理

### ユーザーのITリテラシー

- Chrome拡張機能をインストールできるレベル
- 基本的なブラウザ操作ができる

---

## 3. 機能要件

### 3.1 メディアファイル検出

#### 検出対象

| 種類         | 検出方法                                | 対象形式                   |
| ------------ | --------------------------------------- | -------------------------- |
| 動画ファイル | `<video>` タグ（src属性、source子要素） | MP4, WebM, MKV, AVI, MOV等 |
| 音声ファイル | `<audio>` タグ（src属性、source子要素） | MP3, WAV, AAC, OGG等       |
| リンク       | `<a>` タグ（href属性の拡張子）          | 上記すべて                 |

#### 検出条件

- 最小ファイルサイズ制限: なし
- 重複URL除外: 同一URLは1つのみ表示
- blob URL: 検出対象外

#### 自動取得情報

- URL（必須）
- ファイル名（URLから抽出）
- ファイル形式（拡張子またはMIMEタイプ）
- タイトル（title属性があれば取得）

---

### 3.2 動画ダウンロード

#### 基本動作

1. 検出した動画URLからそのままダウンロード
2. Chrome Downloads APIを使用
3. ファイル名はURL末尾から自動抽出
4. ファイルサイズ制限なし

#### ダウンロード方法

- 個別ダウンロード: 各アイテムの「動画ダウンロード」ボタン
- 一括ダウンロード: チェックボックスで選択 → 「選択した項目を動画ダウンロード」ボタン

---

### 3.3 音声抽出（MP3変換）

#### 処理方法

- **ffmpeg.wasm**（WebAssembly版ffmpeg）を使用
- ブラウザ内で完結（外部サーバー不使用）
- Service Workerでバックグラウンド処理

#### 変換仕様

- 入力形式: MP4, WebM, MKV, AVI, MOV等（ffmpegが対応する全形式）
- 出力形式: MP3
- ビットレート: 128kbps（標準）
- サンプルレート: 44.1kHz

#### ファイルサイズ制限

- **制限なし**
- 大容量ファイルの注意事項を表示（後述）

#### 処理フロー

1. ユーザーが「音声抽出」ボタンをクリック
2. Service Workerにジョブ送信
3. ffmpeg.wasmで動画から音声を抽出
4. MP3形式に変換
5. 進捗状況をリアルタイム表示
6. 変換完了後、自動でダウンロード
7. Chrome通知 + アイコンバッジで完了を通知

#### 並列処理

- 最大同時変換数: 3つ
- 4つ目以降はキューに追加

---

### 3.4 メタデータ編集

#### 編集可能な項目

| 項目         | 説明           | デフォルト値           |
| ------------ | -------------- | ---------------------- |
| タイトル     | 曲名・動画名   | ファイル名から自動取得 |
| アーティスト | アーティスト名 | 空白                   |
| アルバム     | アルバム名     | 空白                   |
| 年           | リリース年     | 空白                   |
| ジャンル     | ジャンル       | 空白                   |
| コメント     | 備考           | 空白                   |

#### 編集タイミング

- ダウンロード前に任意で編集可能
- 「編集」ボタンをクリック → モーダルウィンドウが開く
- 編集せずにそのままダウンロードも可能

#### メタデータの反映

- **ファイル名**: `{アーティスト} - {タイトル}.mp3` 形式
- **ID3タグ**: MP3ファイルに埋め込み（ffmpeg.wasmのメタデータオプション使用）

---

### 3.5 複数選択・一括操作

#### 選択UI

- 各アイテムにチェックボックス表示
- 「すべて選択」チェックボックスも配置

#### 一括操作ボタン

| ボタン                         | 動作                                                |
| ------------------------------ | --------------------------------------------------- |
| 選択した項目を動画ダウンロード | チェックした動画をそのままダウンロード              |
| 選択した項目を音声抽出         | チェックした動画から音声を抽出してMP3でダウンロード |

---

### 3.6 バックグラウンド処理

#### Service Workerでの処理

- ポップアップを閉じても変換処理は継続
- タブを切り替えても処理継続
- ブラウザを最小化しても処理継続

#### 処理状態の永続化

- Chrome Storage（local）に処理中ジョブを保存
- ブラウザを再起動しても復元可能

#### 完了通知

1. **Chrome通知**: 「動画の変換が完了しました」
2. **アイコンバッジ**: 完了した件数を表示（例: 「3」）
3. ポップアップを開くと完了リストを表示

---

### 3.7 進捗表示

#### 表示内容

| 項目               | 説明                                  |
| ------------------ | ------------------------------------- |
| ステータステキスト | 「変換中...」「ダウンロード準備中」等 |
| プログレスバー     | 0%〜100%で進捗を視覚化                |
| 推定残り時間       | 「残り約2分30秒」                     |
| 処理速度           | 「0.8x」（リアルタイム処理速度）      |

#### 進捗の計算方法

- ffmpeg.wasmのログから進捗を取得
- ファイルサイズと処理済みバイト数から残り時間を推定

---

### 3.8 キャンセル機能

#### キャンセルボタン

- 変換中のアイテムに「キャンセル」ボタンを表示
- クリックでffmpegプロセスを強制終了
- 部分的に生成されたファイルは削除

---

### 3.9 注意事項表示

#### 表示タイミング

- ポップアップの下部に常時表示
- 音声抽出ボタンをクリックした際にも確認ダイアログで表示

#### 注意事項の内容

```
【注意事項】
• 大容量ファイル（1GB超）の処理には10分以上かかる場合があります
• 変換中はメモリを多く使用します。他のタブを閉じることを推奨します
• ブラウザの設定で「ダウンロード前に保存場所を確認」をOFFにすると自動保存されます
• 著作権法を遵守し、個人利用の範囲でご使用ください
```

## 4. 非機能要件

### 4.1 パフォーマンス

- メディア検出: 1秒以内
- ポップアップ起動: 0.5秒以内
- 音声抽出速度: ファイルサイズに依存（目安: 100MBで2-5分）

### 4.2 使いやすさ

- ワンクリックでダウンロード可能
- メタデータ編集は任意（スキップ可能）
- 進捗状況を常に表示

### 4.3 信頼性

- 変換エラー時はエラーメッセージを表示
- 処理中にブラウザがクラッシュしても、再起動後に処理を再開

### 4.4 セキュリティ

- すべての処理をブラウザ内で完結（外部サーバーへのアップロードなし）
- ユーザーデータは端末内のChrome Storageのみに保存

### 4.5 互換性

- Chrome 90以降に対応
- Manifest V3に準拠

## 7. 画面遷移フロー

### 基本フロー

1. ユーザーがWebページを開く
2. 拡張機能アイコンをクリック
3. ポップアップが開き、自動でページをスキャン
4. 検出したメディアファイルをリスト表示
5. ユーザーが操作（ダウンロード / 音声抽出 / 編集）

### 音声抽出フロー

1. 「音声抽出」ボタンをクリック
2. Service Workerにジョブ送信
3. ポップアップにプログレスバー表示
4. ポップアップを閉じても処理継続
5. 変換完了後、Chrome通知
6. アイコンバッジに完了件数表示
7. ポップアップを再度開くと完了済みアイテムに「ダウンロード」ボタン

## 8. エラーハンドリング

### エラー種類と対処

| エラー種類       | 発生条件                   | 対処方法                                                     |
| ---------------- | -------------------------- | ------------------------------------------------------------ |
| ファイル取得失敗 | URLが無効、CORS制限        | エラーメッセージ表示「ファイルを取得できませんでした」       |
| ffmpeg変換失敗   | 非対応形式、破損ファイル   | エラーメッセージ表示「変換に失敗しました」                   |
| メモリ不足       | 大容量ファイル処理         | エラーメッセージ表示「メモリ不足のため処理できませんでした」 |
| ダウンロード失敗 | 権限なし、ディスク容量不足 | Chromeのダウンロードエラーを表示                             |

---

## 9. 制約事項

### 技術的制約

- ffmpeg.wasmのサイズ: 約30MB（初回ロード時にダウンロード）
- メモリ使用量: 動画サイズの2-3倍を消費
- 同時変換数: 最大3つ

### サイト制約

- CORS制限のあるファイルはダウンロード不可
- DRM保護コンテンツは処理不可
- ストリーミング専用サイト（YouTube等）は検出困難な場合あり
