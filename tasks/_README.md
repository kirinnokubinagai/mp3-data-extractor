# タスク実装ガイド

## タスクファイルの読み方

各タスクファイルは以下の構成:
1. **メタ情報**: 並列グループ、依存、推定時間
2. **概要**: このタスクで何を実装するか
3. **前提条件**: 完了すべきタスク
4. **ゴール**: 完了条件
5. **実装手順**: ステップバイステップ
6. **完了条件**: チェックリスト
7. **次のタスク**: 次に進むタスク

## 並列実行グループ

同じグループのタスクは並列実行可能:
- **グループA**: タスク04-10（Atoms）
- **グループB**: タスク11-15（Molecules）
- **グループC**: タスク16-23（Organisms）
- **グループD**: タスク24（Templates）
- **グループE**: タスク25-26（Content Script）
- **グループF**: タスク27-31（Service Worker）
- **グループG**: タスク32-34（Data Layer）
- **グループH**: タスク35-40（Integration）
- **グループI**: タスク41-43（TDD Unit）
- **グループJ**: タスク44-48（Polish）

## 実装の流れ

1. Setup（01-03）を順次実行
2. グループAを並列実行
3. グループBを並列実行
4. ...（以降同様）

## 注意事項

- Chrome拡張機能なのでビルドツールは使用しない
- Vanilla JavaScriptで実装
- Tailwind CSS CDNを使用
- Lucide Icons CDNを使用
