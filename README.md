# mp3-finder

Chrome拡張で現在開いているページからMP3リンクを検出し、一覧表示してダウンロードできます。

## 使い方

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選択
4. MP3を含むページを開いて拡張アイコンをクリック

## できること

- ページ内の `<audio>` / `<source>` / `<a>` からMP3リンクを検出
- クリックでダウンロード開始

## 補足

- ストリーミング(M3U8など)や `blob:` URLの音源は対象外です。
- ダウンロードはChromeのダウンロード機能を使用します。
